Privacy Policy

Extension: YouTube Comment Audience Insights
Last updated: May 2025

1. Overview

YouTube Comment Audience Insights is a Chrome extension that performs AI-powered sentiment analysis on publicly available YouTube video comments. We are committed to protecting your privacy.

2. Data We Access

The extension accesses the following data solely to provide its core functionality:

  • Active tab URL — to detect the YouTube video the user is currently watching and extract the video ID.
  • YouTube comment text — publicly available comments are fetched via the YouTube Data API v3 for sentiment analysis.

3. Data We Do Not Collect

We do not collect, store, or share:

  • Personally identifiable information (name, email, address)
  • Browsing history or web activity
  • Authentication credentials
  • Any data unrelated to YouTube comment analysis

4. Data Transmission

YouTube comment text is sent to our secure backend API for sentiment analysis processing. This data is used solely to generate results displayed within the extension and is not stored or shared with third parties.

5. Third-Party Services

The extension uses the YouTube Data API v3 (provided by Google) to fetch public comments. Use of this API is subject to Google's Privacy Policy.

6. Changes to This Policy

We may update this privacy policy from time to time. Any changes will be reflected on this page with an updated date.

7. Contact

If you have any questions about this privacy policy, please open an issue on our GitHub repository.
